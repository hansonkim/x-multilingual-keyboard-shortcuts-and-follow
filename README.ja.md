# X Multilingual Keyboard Shortcuts & Follow (日本語)

**言語 (Languages)**: [English](README.md) | [한국어](README.ko.md) | [中文](README.zh.md) | [日本語](README.ja.md)

[![Chrome Web Store](https://img.shields.io/badge/Chrome%20Web%20Store-v1.0.7-1d9bf0?logo=googlechrome&logoColor=white)](https://chromewebstore.google.com/detail/helbbdgikebbpbjjejmkkappejlhaglf)

IME（日本語かな・韓国語・中国語・ロシア語・アラビア語・全角入力など）を英数モードに切り替えることなく、**X.com (旧Twitter) のすべての標準キーボードショートカット（`?`）**に加えて、**フォロー/フォロー解除（`F`）**、**確認ダイアログ操作（`Y`/`N`）**、**フォロワー/フォロー中タブ移動（`G` `V` / `G` `W` / `G` `O`）**をそのまま使える Chrome 拡張機能です。

## 主な機能

1. **フォロー / フォロー解除 / フォローバックのショートカット（デフォルト：`F`）**
   - **プロフィール＆ポスト詳細（status）ページ**：ユーザープロフィールやポスト詳細ページで `F` キーを押すと、即座に**フォロー**、**フォロー中（解除）**、**フォロー백**ボタンをクリックします。
   - **フォロワー・フォロー中リスト（`/verified_followers`、`/followers`、`/following`）**：`J` / `K` キーでユーザーを選択（長押しで連続スクロール対応）し、`F` キーで選択中のユーザーをフォロー・フォローバック・フォロー解除できます。
   - **ホバーカード**：プロフィールのホバーカードが表示されている時は、ホバーカード内のフォロー/解除ボタンを優先して操作します。
2. **確認ダイアログのショートカット（`Y` / `N`）**
   - フォロー解除・ミュート・ブロックの確認モーダルが表示された際、マウスを使わずに `Y` で確認（実行）、`N` でキャンセルできます。
3. **フォロワー / フォロー中タブへの直接移動（`G` `V` / `G` `W` / `G` `O`）**
   - X.com のどのページからでも `G` `V`（**認証済みフォロワー**）、`G` `W`（**フォロワー**）、`G` `O`（**フォロー中**）を押すだけで該当タブへ瞬時に移動します。
4. **X.com（`?`）全標準ショートカットの多言語 IME 完全対応**
   - 日本語（かな/全角）、韓国語、中国語などの IME がオンのままでも、すべての X.com 標準ショートカット（`?`、`J`、`K`、`Space`、`.`、`N`、`/`、`L`、`R`、`T`、`S`、`B`、`U`、`X`、`Enter`、`O`、`I`、`M`、引用ポスト `E`、`G + H/E/N/R/P/F/T/L/I/M/G/C/S/B/U/D`、`A + D/Space/M`）がそのまま動作します。
5. **画面上のショートカットヒント表示 / 非表示切り替え**
   - 各ボタンやメニューの文字色に合わせた自然なショートカットラベルを表示します。フォロワー/フォロー中リストでは `J`/`K` で選択された行にのみ `F` ラベルが表示されます。拡張機能のポップアップからいつでもオン/オフを切り替えられます。
6. **フォローキーのカスタマイズ＆入力欄の自動判定**
   - ポップアップからフォロー用ショートカットを任意のキーや修飾キーの組み合わせに変更可能です。ポスト作成欄・返信・検索バー・DM の入力中はショートカットが自動的に無効化されます。

## ショートカット一覧

### 拡張機能で追加されるショートカット

| ショートカット | 動作内容 |
| --- | --- |
| `F` *(変更可能)* | プロフィール・ポスト詳細・ホバーカード・`J`/`K` 選択中のユーザーをフォロー / フォロー解除 / フォローバック |
| `Y` / `N` | フォロー解除・ミュート・ブロック確認ダイアログで確認（`Y`）/ キャンセル（`N`） |
| `G` の後に `V` | **認証済みフォロワー**（`/verified_followers`）を開く |
| `G` の後に `W` | **フォロワー**（`/followers`）を開く |
| `G` の後に `O` | **フォロー中**（`/following`）を開く |
| `E` | リポストメニューを開いて**引用（Quote）**を直接選択 |

### X.com 標準ショートカット（日・韓・中 多言語 IME 自動変換対応）

| ショートカット | 動作内容 |
| --- | --- |
| `?` / `.` | ショートカット一覧を表示（`?`）/ 新しいポストを読み込む（`.`） |
| `J` / `K` *(長押し対応)* | 次 / 前のポストまたはユーザーへ移動 |
| `Space` / `Enter` | ページスクロール（`Space`）/ 選択したポストを開く（`Enter`） |
| `N` / `⌘+Enter` | 新規ポスト作成（`N`）/ ポスト送信（`⌘+Enter`） |
| `/` | 検索バーにフォーカス |
| `L` / `R` / `T` | いいね（`L`）/ 返信（`R`）/ リポスト（`T`） |
| `S` / `B` | 共有（`S`）/ ブックマーク（`B`） |
| `U` / `X` | ミュート（`U`）/ ブロック（`X`） |
| `O` / `I` / `M` | 画像を拡大（`O`）/ DM ドック（`I`）/ 動画ミュート（`M`） |
| `G` + `H/E/N/R/P/F/T/L/I/M/G/C/S/B/U/D` | ホーム、話題を検索、通知、연絡（メンション）、プロフィール、下書き、予約済み、いいね、リスト、メッセージ、Grok、Creator Studio、設定、ブックマーク、アカウント切り替え、表示設定へ移動 |

## インストール方法

1. **Chrome ウェブストア**：[Chrome ウェブストア](https://chromewebstore.google.com/detail/helbbdgikebbpbjjejmkkappejlhaglf) から直接インストールできます。
2. **手動インストール（デベロッパーモード）**：
   - リポジトリをクローン：
     ```bash
     git clone https://github.com/hansonkim/x-multilingual-keyboard-shortcuts-and-follow.git
     ```
   - Chrome で `chrome://extensions/` を開き、右上の**デベロッパー モード**を有効にします。
   - **パッケージ化されていない拡張機能を読み込む**をクリックし、このフォルダを選択します。

---

## プライバシー

本拡張機能は `https://x.com/*` および `https://twitter.com/*` 上でのみ動作し、`chrome.storage` はショートカット設定のローカル保存にのみ使用されます。個人情報や閲覧履歴、アカウント情報の収集・外部送信は一切行いません。
